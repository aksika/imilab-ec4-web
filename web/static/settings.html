Add a camera

Choose a camera from the Imilab account. The IoT ID is filled from the cloud device list. Cameras that belong to another location can still be added; if a saved LAN address is outside this Mac’s network, Start fails immediately with a rebind message.
The IoT ID is not derived from the LAN: it is the Alibaba identity of the cloud device. Only cameras returned by the account’s cloud list can be added here. A “LAN saved” label means an address was bound earlier; it does not prove the camera is awake. Sleeping battery cameras can be absent from a scan.

Cameras on the LAN

Scan the local network for camera-like hosts. Known camera IP/MACs are matched automatically; a new camera can be remembered from the results.
The scan is a local ARP/ping sweep plus TCP fingerprinting. It does not use the cloud relay. Wake a battery camera first if it is asleep.
