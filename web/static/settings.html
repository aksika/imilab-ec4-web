Imilab account

Sign in to refresh camera access automatically. The password is stored by the local helper in the macOS Keychain — not in a cookie or the page.
Checking session…
The browser can offer to save this password via its own password manager. The helper stores it in Keychain so the camera session can be refreshed even after the browser is closed.

Cameras on the LAN

Scan the local network for camera-like hosts. Known camera IP/MACs are matched automatically; a new camera can be remembered from the results.
The scan is a local ARP/ping sweep plus TCP fingerprinting. It does not use the cloud relay. Wake a battery camera first if it is asleep.
